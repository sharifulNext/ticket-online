## 📌 Project Overview

TicketSphere is a full-stack ticket booking system designed with a modern SaaS-style interface. The platform supports multiple ticket categories including flights, trains, buses, concerts, events, and movies.

The application provides:

- Secure authentication
- Ticket search and filtering
- Interactive seat selection
- Online payment integration
- QR-based digital tickets
- Booking management
- Admin analytics dashboard
- AI ticket recommendation system
